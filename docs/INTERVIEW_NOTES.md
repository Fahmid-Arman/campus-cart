# Technical Interview Notes

## Key Concepts Demonstrated
- **Full-stack Integration**: Seamless data flow between React frontend and Node.js/Express backend.
- **State Management**: Efficient use of Redux Toolkit and RTK Query for caching and API synchronization.
- **RESTful API Design**: Logical endpoint structuring following industry standards.
- **Security**: Password hashing with Bcrypt, authentication via JWT stored in HTTP-only cookies to prevent XSS attacks.
- **Database Management**: Schema modeling with Mongoose and handling relationships (e.g., Seller-Product, Buyer-Message).
- **Responsive Design**: Mobile-first UI using React-Bootstrap.

## Challenges Overcome
- **Real-time Messaging**: Designing a polling-based messaging system that provides a smooth user experience while managing server load.
- **Complex State**: Synchronizing the shopping cart and seller listing states across different components.
- **Role-based Access**: Implementing robust middleware to separate regular users, sellers, and administrators.

## Key Learning Outcomes
- Deepened understanding of asynchronous programming in JavaScript.
- Mastered the lifecycle of a full-stack request from the UI button click to the database update.
- Gained experience in designing user-centric features for a niche community.
