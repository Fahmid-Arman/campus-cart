# Project Overview: Campus Cart

## Introduction
Campus Cart is a specialized C2C (Consumer-to-Consumer) marketplace designed specifically for the BRAC University student community. The platform facilitates the buying and selling of used academic materials, electronics, and other essentials within a trusted campus environment.

## Problem Statement
Students often struggle to find affordable textbooks, electronics, and dorm essentials. While generic marketplaces exist, they lack the trust and convenience of a campus-specific platform. Campus Cart solves this by providing a localized, secure, and student-only marketplace.

## System Architecture
The project follows the MERN (MongoDB, Express, React, Node.js) stack architecture:

- **Frontend**: Built with React and Redux Toolkit for state management. Uses React-Bootstrap for a responsive and clean UI.
- **Backend**: Node.js and Express.js REST API providing secure endpoints for data management.
- **Database**: MongoDB (NoSQL) for flexible and scalable data storage.
- **Authentication**: JWT (JSON Web Tokens) with secure cookie-based storage.

## Target Audience
- BRAC University Students
- Faculty Members
- Campus Residents
