# Feature List

## User Authentication & Profile
- **Registration & Login**: Secure account creation using Student ID.
- **Profile Management**: Update user information and view order history.
- **Security**: JWT-based authentication with protected routes.

## Product Marketplace
- **Search & Filter**: Keyword search and category-based filtering for products.
- **Product Details**: Detailed view with condition, price, and seller information.
- **Reporting System**: Flag inappropriate listings for administrative review.

## Seller Dashboard
- **Listing Management**: Create, edit, and delete own product listings.
- **Image Upload**: Upload product photos to local storage.
- **Order Tracking**: Manage and view the status of sold products.

## Communication
- **Real-time Chat**: Integrated messaging system for buyers and sellers to negotiate and coordinate.
- **Unread Notifications**: Visual indicators for new incoming messages.

## Shopping Cart & Checkout
- **Cart Management**: Add/remove products from the shopping cart.
- **Secure Checkout**: Seamless transition from cart to order placement.

## Admin Moderation
- **User Management**: View and suspend users if necessary.
- **Report Management**: Review reported products and take action (delete/resolve).
- **Global Overview**: Manage all orders and product listings across the platform.
